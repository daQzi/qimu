## 用户验收

1. 按接入指南生成 `model-review`，检查目录与成品包报告摘要一致；报告明确显示运行条件未验证。重复初始化/打包应拒绝覆盖。
2. 修改错误的操作字段，确认校验失败并给出文件位置；不允许带错误继续打包。
3. 安装插件并授权，在首页工作台填写普通文案目标和已配置的模型，确认能够发现技能/操作；无需视频或画布。
4. 报价前不执行收费生成；批准后生成草稿。修改文本后明确确认，最终结果应使用修改后的文本，不自动勾选批准。
5. 检查另一个账号无法读取运行；历史插件、原画布流程连线与主线分镜批量输入仍可用。
6. 使用备份副本验证升级，核对历史 Run 与工具库/收藏，不直接以生产库首次试验。
