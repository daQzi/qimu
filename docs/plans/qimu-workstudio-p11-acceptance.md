# P11 统一验收：视频分析与出海替换方案

集成目标 `codex-workstudio`，基于已验收 P10 和 fork main。P11 补齐媒体探测、抽帧、可配置音轨理解与可视化修正。未合入 main、未推送或部署、未调用付费模型。数据库仍为 schema 37。

## 安装准备

1. 更新前后端，安装 `video-localization-1.0.1.yingce-plugin`，启用并授权。后端镜像包含 ffmpeg/ffprobe；宿主机启动须确认两者在 PATH。
2. 配置有效系统视频理解模型、渠道、价格、视频数量/大小及提示词/输出额度。确实支持原视频声音时，在文本模型视频引用配置打开“视频音轨理解”；未开启时只分析画面和字幕。
3. 画布上传原片，在 Agent 引用 localize 技能或进入出海工作台，填写原片、真实模型 ID、国家、语言、风格。模型结构化字段可由 Agent 查询目录填写，不需要密钥。

## 一次完整流程

1. 核对模型、渠道域名、原片、音轨能力和授权额度。批准之前不外发视频、不创建收费任务。
2. 批准后先探测再调用模型。工具缺失或文件损坏应失败并释放预留，不能继续请求上游。报告 source.digest 是文件 SHA-256，时长来自 ffprobe。
3. 把分析结果和待修正输入放到画布。检查镜头、人物、场景、道具、对白和声音事件。开启音轨理解时检查说话人、听不清标记及背景音描述；关闭时不得声称已分析音轨。
4. 合并人物，检查证据保留和对白说话人同步；修改名称、镜头时间、运镜、对白和说话人。点击证据定位原片，点击“提取当前时间画面”查看抽帧。时间单位为毫秒，模型镜头边界仍需核对。
5. 保存草稿后刷新，修改不丢失；旧 revision 提交应冲突。JSON 模式填写错误原片摘要、不存在的 shotId、越界时间或伪造音轨能力，应拒绝提交并保留草稿。
6. 提交报告后再次审批替换建议，只发送报告文本和目标要求，不再次发送原片。
7. 修改替换目标/提示词，选择已有素材或上传。声音项接受音频，视觉项接受图片/视频；他人或未就绪素材应拒绝。确认后方案冻结、历史保留，不创建成片任务。
8. 派生新版本仅修改 confirm：复用分析和建议，不重复付费或覆盖原版本；修改上游步骤仅重跑受影响下游。资源或报价变更不能无条件复用。

## 异常与隔离

- 排队取消不请求模型；执行中取消沿用原账务规则，迟到结果不复活。
- 无效 JSON、错误来源和实体引用明确失败；已调用模型的费用如实保留，不自动付费修复。
- 账号切换、越权读取原片/抽帧/素材、资源变更和模型配置变化均须拦截。
- 检查明暗主题、画布滚动/缩放、焦点、窄屏、刷新和重新打开流程。

## 本地验证

- 补齐版 SQLite/PostgreSQL P11 + Workbench 专项通过；真实媒体视频 Worker 的双库 race 通过（约 63 秒），覆盖音轨结果、实际文件摘要、来源变更拒绝、坏文件不请求模型且退还预留。
- Go mediaanalysis、plugins/authoring/contracts 与 HTTP handler 测试通过；前端插件相关 123 项测试与生产构建通过，构建仍有原有大分块提示。

- 前版覆盖报价/审批/钱包、流程预填/冻结、画布投影、派生复用与取消；补齐版增加真实 FFmpeg 探测/抽帧、视频 Worker、音轨合同、来源防篡改、探测失败不外发/不收费及人物合并测试。
- 用户样片仅本机探测和抽帧：218578 ms，两个音视频流，SHA-256 与原文件一致；片头、中段、片尾可抽帧，未上传模型。
- 模型使用 localhost 模拟响应验证链路，不能证明真实识别质量。真实模型、费用和浏览器交互由用户统一验收。

P11 交付可确认的分析与替换方案。配音、背景音处理、字幕合成属于 P12，视觉替换及完整成片属于 P13，本次不提前进入。
