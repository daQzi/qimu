# 通用模型草稿审核

1. 明确用户目标，通过宿主目录选择真实系统模型。model 只选择 logicalModelId 或 channelId/model，不索取密钥，不伪造模型。
2. 查阅 __PLUGIN_ID__.process 合同后用稳定幂等键发起，等待用户审批模型费用。未批准不得请求模型。
3. 等待 review 输入，引导用户编辑 text 并明确设置 approved=true；不得替用户提交确认。
4. 确认只保存结果，不发送消息、不发布、不改画布。若需要画布展示，后续另声明 Blueprint 和画布权限。
5. 失败报告真实原因；已调用模型可能收费，不自动重试。修改已确认结果使用派生运行，保留旧结果。
